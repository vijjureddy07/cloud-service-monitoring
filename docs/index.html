INFRASTRUCTURE / LAB 01

Service monitoring & incident response

Simulate a healthy service, a failing service, retrying health checks, JSON logs and recovery. Built for support and entry-level infrastructure troubleshooting practice.

This is documentation, not a live production status page. Status examples in this project are created locally and are not claims about any real system.
MONITORING

Health probes

HTTP /healthz checks, response codes, timeouts, retries and exit codes.

CONTAINERS

Docker + Nginx

A web service behind a reverse proxy, bound to the loopback interface.

INCIDENTS

Runbooks

Repeatable outage injection, log review, root-cause notes and recovery.

Run it locally

docker compose up -d --build
python3 scripts/check_service.py
python3 scripts/summarize_checks.py
# Simulate incident:
DEMO_FAIL_MODE=1 docker compose up -d --force-recreate
python3 scripts/check_service.py
